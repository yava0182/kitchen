## Легенда

- **OK** — раздел есть, смысл тот же
- **PARTIAL** — есть, но неполный / другое имя
- **MISS** — в Clodis нет (нужна выгрузка из PP + страница)
- **PLUS** — только у нас (оставить, обсуждать отдельно)

## Карточка элемента — слои

### Канон Save (pp4) — админка → диск

- Save **мержит** `data.*` (клиент: база = последний load; сервер: `{...prevData, ...payload}`), не затирает whitelist’ом.
- Материалы: глобальные дефолты групп — только для **новой** карточки (id=0), не поверх существующей.

### Слой 1 «Основные» (pp3/pp4) — принят только после чеклиста

Реф: `vendor/catalog-item-edit-REFERENCE.html`. **Clodis+ не трогаем** (опоры, пенал, каталог в комнате, метка двери, пара, цельная дверь, placementKind).
