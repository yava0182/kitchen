## 🔄 Отличия от референса

### Что делаем по-другому

#### 1. Структура ID и классов
**В референсе:** Используются URL-пути как ID  
**В нашей реализации:** Используем короткие ID (например: `#materials` вместо `/catalog/materials`)  
**Причина:** У нас SPA, не нужны полные URL

#### 2. Названия классов
**В референсе:** `ibox`, `ibox-title`, `ibox-content`  
**В нашей реализации:** Можно использовать свои имена (например: `card`, `card-header`, `card-body`)  
**Причина:** Избежать копирования структуры

## 🏗️ Архитектура решения

### Структура добавления вкладки:

```html
<!-- 1. Пункт меню -->
<li>
  <a href="#page-id" data-page="page-id">
    <i class="fa fa-icon"></i>
    <span class="nav-label">Название</span>
  </a>
</li>

<!-- 2. Контейнер страницы -->
<div id="page-id" class="admin-page">
  <div class="page-heading">
    <h2>Заголовок страницы</h2>
  </div>
  <div class="wrapper-content">
    <div class="ibox">
      <div class="ibox-title">
        <h5>Подзаголовок</h5>
      </div>
      <div class="ibox-content">
        <!-- Контент страницы -->
      </div>
    </div>
  </div>
</div>
```

### JavaScript для переключения (уже есть):
```javascript
// Обработчик клика на меню
document.getElementById('side-menu').addEventListener('click', function(e) {
  // Логика переключения страниц

```

## 🧪 Тесты

### Тест 1: Переключение вкладки
**Условие:** Кликнуть на пункт меню  
**Ожидаемый результат:** 
- Старая страница скрывается
- Новая страница показывается
- Пункт меню становится активным

**Как проверить:**
1. Открыть админ панель
2. Кликнуть на новый пункт меню
3. Проверить что страница отображается
4. Проверить что другие страницы скрыты

### Тест 2: Контент страницы
**Условие:** Страница открыта  
**Ожидаемый результат:** Контент отображается корректно

---

## ⚠️ Риски и ограничения

### Риск 1: Конфликт ID
**Описание:** Новый ID может конфликтовать с существующими  
**Митигация:** Проверить уникальность ID перед добавлением

### Риск 2: JavaScript ошибки
**Описание:** Новый JavaScript может сломать существующий функционал  
**Митигация:** Тестировать после каждого изменения
