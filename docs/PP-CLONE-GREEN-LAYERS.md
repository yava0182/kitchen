# Очередь зелёных слоёв (W2–W3)

Один слой = одно сообщение Auto. Шаблон — `.cursor/rules/how-to-write-tasks.mdc`.  
Не мешать НМУ / сетку / накладки / цену в одном сообщении.

Связь: [PP-CLONE-MONTH.md](PP-CLONE-MONTH.md).

## Уже закрыто / заморожено (не трогать без явной фразы)

| Слой | Статус |
|------|--------|
| Прямая 600 + жертва | канон / rule `straight-600-sacrifice` |
| Накладки колонки 16 мм | канон закрыт (край пенал↔антресоль отложен) |
| НМУ return / freeze 1.42 | `npm run freeze:nmu` — не ломать |
| Autosave draft v2 база | Stage3+ есть; добить только дыры из очереди |

## Очередь до DoD (порядок)

### G1 — Прямая: регресс приёмки сетки

```
Слой: сетка прямой
Модуль: НМ ряд
Сейчас: проверить 2000 → 600|600|200|600 жертва zi=2; карандаш жмёт только жертву
Должно: как канон straight-600-sacrifice
Проверка: ?v=… после подтверждения bust
Не трогать: НМУ, фасады, цену, столешку
```

### G2 — НМ: цоколь из дерева админки

```
Слой: цоколь
Модуль: НМ
Сейчас: …
Должно: доски type/layout_role plinth из карточки; низ = h_bottom от пола
Проверка: админ-превью + комната один bust
Не трогать: overlay-прогон, НМУ, фасады
```

### G3 — НМУ: цоколь / стык (только если G2 зелёный)

```
Слой: цоколь угла
Модуль: НМУ
Сейчас: …
Должно: как согласованный канон стыка; без синтетических мешей
Не трогать: catalog_44 size/pos freeze, карточку 45 ради слота
```

### G4 — Столешка: админка → комната

```
Слой: столешка
Модуль: НМ ряд / НМУ
Сейчас: …
Должно: геометрия из дерева/vars карточки; ячейка = столешка (канон НМУ)
Не трогать: цену, фасады, dump merge
```

### G5 — Пояса MID/TOP: независимые сетки без «навязать гармонию»

```
Слой: пояса mid/top
Модуль: НШ1 / НШ2
Сейчас: …
Должно: place/rebuild по артикулу; без автокопирования низа (kitchen-brain-harmony)
Не трогать: Brain «зашить симметрию», НМУ
```

### G6 — L/U угол: persistence + Joint без дублей

```
Слой: L-joint persistence
Модуль: угол
Сейчас: …
Должно: save/load без дублей Joint; Continue ок
Не трогать: прямую жертву, накладки (кроме регресса)
```

### G7 — Save/load демо-сценарий

```
Слой: draft save/load
Модуль: кухня целиком (прямая + угол минимум)
Сейчас: …
Должно: New → расставить → F5 → Continue: сетка, глубины, высоты, kitchenProject
Не трогать: прайс, UI админки
```

## Правило стоп-линии

2–3 сессии без зелёной приёмки по одному слою → смена подхода (порт узкого куска из `vendor/main_core_v2_part*`), не миллиметровый патч.
