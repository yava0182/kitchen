# Канон НМУ (угловой нижний)

Эталон. Меняется только фразой: **«сменить канон НМУ»** + что именно.  
Агент: `.cursor/rules/nmu-canon.mdc`.

---

## Ячейка = столешка (главное)

**Сверху: синяя ячейка и столешка — одно место (W × Dwt).**  
Ничего не торчит за ячейку. Корпус / приставка / отступ — **под** столешкой, внутри габарита.

Отступ (`clear`) — щель **внутри** ячейки у боковой стены, не сдвиг столешки наружу.

```
W = 1050 (пример) = столешка по U
= фасадная нога (W − D − clear) + приставка D + clear у стены  (всё под столешкой)
```

- **D** на place = project depth из «Управление кухней» → ширина приставки (`corner_return_mm`).
- Отдельной var «нога» нет: нога = остаток.
- **Уголок 40 не входит** в сумму 1050 — он на фасаде приставки.
- Посадка в зону для НМУ — по bbox **со столешкой**, не corpus-only.

## Две переменные (корень НМУ / catalog_44)

| Var | Смысл | Канон |
|-----|--------|--------|
| `corner_return_mm` | ширина приставки (= D на place / свой карандаш) | обычно **550** |
| `corner_return_depth_mm` | толщина оболочки слота на фасаде | **40** |

**Старт:** place НМУ — project D (обычно **550**), соседа не угадывать.  
**После place:** глубина корпуса и приставка НМУ — только свой карандаш. Смена D соседа НМ **не** трогает НМУ (`followCorner` выкл.).

**Настройки кухни + карандаш (канон 1.42, ЗАМОРОЖЕН):**
- **Управление кухней** D=460/510/550 → глобально: корпус D, rear=100/50/10; place НМУ: clear=rear, return=D.
- **Отступ модуля**: приставка `worktop−40−clear`, **нога стоит** (`_cornerReturnDFromClearMm`).
- **Ширина ячейки** → жмётся **нога**.
- **Глубина модуля**: Z; clear/return не затирать (project sync — отдельно).

## Слот приставки (catalog_44) — не трогать

`layout_role: corner_return` · live `catalog_45`

```
size.x = v:corner_return_mm
size.y = s:y - v:h_bottom
size.z = v:corner_return_depth_mm
pos.x  = v:corner_return_pos_x   /* W − rear − D: зад вровень с НМ; при 550 rear=10 */
pos.y  = v:h_bottom
pos.z  = s:z
pivot  = -1, -1, -1
```

При своём D: `corner_return_pos_x` = W − rear − D
(rear = столешница − 40 − D). Соседский D не подставлять.

## Рецепт внутри карточки приставки (catalog_45)

### Деталь (основная панель)

Это панель приставки (ширина = `corner_return_mm`):

- ширина тянется от слота: `size.x = s:x`;
- на передней фаске: `pos.z = s:z`, `pivot.z = +1`;
- `side = front`, `detailTypeId = front_front`.

### Уголок (по умолчанию 40×40)

Ориентацию/стороны в карточке **не крутить** — уже выставлено вручную.  
Канон size/якорь (как было до ошибочного «разворота»):

```
size:  x = 40,  y = s:y,  z = 40
pos:   x = s:x (левый) | -40 (правый),  y = 0,  z = 0
pivot: -1, -1, -1
```

Если «не заподлицо» — сначала слот НМУ (pos/pivot слота), не разворот уголка.

## Дерево НМУ

1. Секция  
2. `cabinet_root` — фасадная **нога**: `size.x = v:corner_leg_mm` (= W − rear − D), не `s:x`  
3. `corner_return` — слот → live catalog_45 (Деталь + Уголок)

Цоколь, двери, цена, столешка — другие слои, после приёмки.
