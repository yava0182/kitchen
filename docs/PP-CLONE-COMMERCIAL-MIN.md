## Узкие слои W4 (после G7)

### C1 — Заявка из комнаты

```
Слой: заявка
Модуль: комната → админка
Сейчас: …
Должно: одна кнопка/шаг отправляет заявку с контактами + id/снимком проекта; видно в «Заявки на расчет»
Не трогать: геометрию, НМУ, прайс-движок
```

### C2 — Ориентир цены

```
Слой: ориентир цены
Модуль: кухня
Сейчас: …
Должно: одно число/диапазон по простым правилам (корпус+фасад+столешка) или «расчёт менеджером»
Не трогать: полный прайс-лист PP, API
```

## Критерий закрытия коммерческого минимума

- [ ] Демо клиенту на одном bust: проект сохраняется и открывается.
- [ ] Заявка уходит и видна в админке.
- [ ] Есть ориентир цены **или** явный UX «цену посчитает менеджер» без обещания полного PP-прайса.
- [ ] Все строки MISS выше остаются stub (не начинать декоры/API «заодно»).
