# Параметры материала: кромка и варианты

## Как устроено

### Два уровня привязки

1. **Ключ материала (materials_keys)** — тип материала, например «ЛДСП», «ХДФ».
   - Страница: редактирование ключа материала (Список материалов → редактировать тип).
   - Поля: **Название**, **Набор кромок** (`edges_set`), «Выбор кромки в меню» (`edge_in_menu`).
   - **Набор кромок** задаётся один раз на тип: из какого набора кромок (edges_keys) пользователь будет выбирать кромку для материалов этого типа.
   - API: `GET /api/catalog/items_get/edges_keys` — список наборов; сохранение в `materials_keys.json` (`edges_set`, `edge_in_menu`).

2. **Элемент материала (material item)** — конкретный материал, например «Дуб Гудзон бискотти».
   - Страница: редактирование элемента материала (вкладка **Параметры**).
   - Здесь:
     - **Набор кромок** — тот же список, что и у ключа; можно переопределить набор для этого материала.
     - **Назначенные кромки** — **несколько** кромок (кнопка «Добавить кромку»): один и тот же материал может оклеиваться кромкой разной толщины. Список хранится в `edge_ids: [id1, id2, ...]`.
   - В конструкторе при нанесении кромки на сторону выпадает **только этот список** назначенных кромок.
   - Данные элемента хранятся в `catalog_items/{controller}.json`. Сервер принимает в теле `edge_set`, `edge_ids`, `variants` и мержит в объект элемента.

### Откуда выбирается кромка

- **Наборы кромок** — справочник **edges_keys** (файл `catalog_items/edges_keys.json`, API `GET /api/catalog/items_get/edges_keys`). Каждая запись — набор с полями `id`, `key`, `name`.
- **Элементы кромок в наборе** — каталог элементов типа `butt_{key}` (например `butt_butts`). Список элементов: `GET /api/catalog/items_get/butt_XXX`, один элемент: `GET /api/catalog/item/butt_XXX/:id`. То есть для набора с `key: "butts"` список кромок загружается как элементы типа `butt_butts`.

Кнопка **«Добавить кромку»** открывает модальное окно выбора кромки из выбранного набора; выбранные кромки добавляются в список «Назначенные кромки». Один материал может иметь несколько назначенных кромок (например одна и та же кромка разной толщины).

### Для чего кромка у материала

Чтобы задать **кромку по умолчанию** для этого плитного материала: какой кромкой оклеивать лист при раскрое в конструкторе. В референсе Clodis и в нашей логике конструктора для детали может использоваться материал (material_id) и при необходимости кромка; если у материала задана кромка по умолчанию, она может подставляться автоматически.

## Варианты (размеры, цена)

Блок **«Варианты»** во вкладке «Параметры» — по референсу Clodis: у одного материала может быть несколько вариантов (разные размеры листа, артикулы, цены).

- Поля одного варианта: название, артикул, длина/ширина/толщина (мм), тип расчёта (р/м², р/м.п), способ ввода цены (ручной/импорт), цена (руб).
- Кнопка «Добавить» добавляет вариант в список; список хранится в элементе материала как массив `variants` (или в `params.variants` — зависит от контракта с конструктором).
- В конструкторе при выборе материала может подставляться выбранный вариант (размеры, цена).

Сохранение: при сохранении элемента материала бандл должен собирать данные из полей «Варианты» и отправлять в payload поле `variants` (массив объектов с полями name, article, length, width, thickness, calculation_type, price_input_type, price и т.д.). Сервер при `item_edit` мержит тело запроса в элемент, поэтому достаточно, чтобы фронт отправлял эти поля.

## Что уже есть в коде

| Что | Где | Статус |
|-----|-----|--------|
| Набор кромок у **ключа** материала | material-key-edit, `material-key-edges-set` | Заполняется из edges_keys, сохраняется в materials_keys |
| Набор кромок у **элемента** материала | material-item-edit → Параметры, `material-edge-set` | Заполняется из edges_keys |
| **Несколько** назначенных кромок | `material-edge-add-btn`, `material-edge-list`, `material-edge-pick-modal` | Реализовано: добавление из набора, сохранение `edge_ids`, в конструкторе показывается только этот список |
| Варианты (поля + список) | `material-variant-*`, `material-variants-list`, `material-variant-add-btn` | В HTML есть; при сохранении бандл пока не читает и не отправляет variants |
| Старые поля (толщина, группа, описание) | Скрыты `display:none`, id те же | Читаются при сохранении из бандла, данные попадают в элемент |

## Рекомендации по доводке

1. **Заполнить «Набор кромок»** во вкладке Параметры элемента материала из `/api/catalog/items_get/edges_keys` (при открытии вкладки или при открытии формы), при загрузке элемента подставлять `item.edge_set` или наследовать от ключа материала.
2. **«Выбрать» (материал кромки):** по клику загружать список кромок выбранного набора (`/api/catalog/items_get/butt_${edgeSetKey}`), показывать модальное окно выбора; после выбора сохранять в элемент `edge_id` (и/или `edge_item_id`) и отображать название в блоке.
3. **Варианты:** при сохранении материала в бандле (или в отдельном скрипте после бандла) читать `#material-variants-list` и поля вариантов, формировать массив `variants` и добавлять в payload; при загрузке элемента заполнять блок «Варианты» из `item.variants`.
4. При загрузке элемента материала подставлять в «Кромка» сохранённые `edge_set`, выбранную кромку (по `edge_id` подгрузить имя и вывести рядом с «Выбрать»).
