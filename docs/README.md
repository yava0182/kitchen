## 🚀 Быстрый старт

### 1. Создать анализ нового компонента

```bash
# Создать файлы анализа и плана для компонента
node scripts/create-analysis.js <component-name>

# Пример:
node scripts/create-analysis.js catalog_item
```

Это создаст:
- `docs/analysis/CATALOG_ITEM_REFERENCE_ANALYSIS.md` - файл анализа
- `docs/plans/CATALOG_ITEM_IMPLEMENTATION_PLAN.md` - файл плана

### 2. Заполнить анализ

1. Открыть файл анализа
2. Изучить референсный код в `planplace_refs/constructor_code_reference/`
3. Заполнить все разделы (см. шаблон)

### 3. Создать план реализации

1. Открыть файл плана
2. На основе анализа создать чеклист задач
3. Определить отличия от референса

### 4. Реализовать

1. Следовать плану
2. Писать код своим стилем
3. Проверять по чеклисту безопасности

## ❓ FAQ

### Как начать работу с новым компонентом?

1. Запустить `node scripts/create-analysis.js <name>`
2. Заполнить анализ
3. Создать план
4. Реализовать

### Что делать если референсный код обфусцирован?

Использовать deobfuscated версии (если есть) или инструменты для деобфускации.

### Можно ли использовать код из референса?

Нет, только изучать и понимать. Код должен быть написан заново.

### Как проверить что код безопасен?

Использовать `CODE_SAFETY_CHECKLIST.md` перед каждым коммитом.
