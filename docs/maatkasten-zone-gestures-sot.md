# Maatkasten — SoT жестов зон (прямая секция)

Источник: live maatkastenonline.be, Step 3 CUPBOARD LAYOUT + скрины 2026-09-15.  
Область: **только прямая ниша** (равные ячейки). L / bay / мост — отдельно, позже.

Код Clodis пока **не** эталон. Эталон — этот файл. Порт: `furniture-manager.js` zone gestures + раскладка зон секции.

---

## 0. Базовая модель (главное)

| Понятие | Maatkasten | Не путать с |
|--------|------------|-------------|
| **Ячейка (cell)** | Равная полоса сетки. Все пустые — одинаковые. | «Зона double с пунктиром пополам» как *пустой* слот |
| **Single-модуль** | Занимает **1** ячейку | |
| **Double-модуль** | Занимает **2** соседние ячейки | |
| **Пусто** | Всегда **ячейка**, не «пустой double» | Empty double-зона |

`layouts = N` → N равных ячеек. Модули кладутся на ячейки.

### Визуал линий на полу (SoT со скринов)

| Что | Линии |
|-----|--------|
| **Одинарная ячейка** (пустая или Single) | Только **сплошные** по краям ячейки |
| **Двойная** (Double = 2 ячейки) | Сплошные по **внешним** краям; **пунктир по середине** (граница двух half) |

Итого: пунктир = «здесь double / две ячейки в одном модуле», не «каждая ячейка».  
Пустая прямая allSingles: ряд сплошных, **без** пунктиров.  
После посадки Double на 2 ячейки: у этого span появляется mid-пунктир.

## 1. Призрак (ghost)

| Модуль | Наведение | Ширина призрака |
|--------|-----------|-----------------|
| Single | на ячейку / half | **1** ячейка |
| Double | на пару ячеек | **2** ячейки |

Призрак **никогда** не растягивается на пустой double-слот, если в руке Single.  
Snap: под курсором — целевая ячейка (для Single) или пара (для Double).

**Баг Clodis (gest6):** Single над double-зоной → `zoneSize` = ширина всей double-зоны → призрак как двухдверный.

---

## 2. Посадка Single в пустой double-ряд (скрин Maatkasten)

Старт: `D D D D` (сплошная–пунктир–сплошная).  
Single слева → **`S | D | D | …`** (иногда хвост single справа):  
- занята **одна** half;  
- соседняя orphan-half **не** остаётся одиночной ячейкой рядом;  
- пустые ячейки **перепакованы** обратно в doubles.

Неверно: вся секция → allSingles; или `S | s_empty | D | D` без repack.
---

## 3. Матрица жестов (занятое / пустое)

Условные обозначения: `S` = single-модуль, `D` = double-модуль, `·` = пустая ячейка.  
Сетка всегда из ячеек ширины 1.

| # | Жест | Было | Стало | Имя |
|---|------|------|-------|-----|
| **A0** | Single → пустая half/ячейка слева | `D D D D` | `S D D S` (или `S D D D` + хвост): **одна** занятая single; пустые half **перепакованы** в doubles; без сироты empty single | place+repack |
| **B** | Single → **занятый** Double (half) | `D_occ …` | кликнутая half = S; вторая half в перепаковку empties | split+repack |
| **C/D** | Double → Single (+ соседняя ячейка) | `S S · ·` / `S · ·` | содержимое 2 ячеек **съесть**; новый `D` на них; пустоты **вправо** | eat-merge |
| **E** | Double → `S` + соседний `D` | `S D D ·` | оба модуля съедены; новый `D` на 2 ячейках от клика; остаток пуст | eat-merge |
| **F** | Double → Double (из каталога) | тот же span | только **начинка** | replace |
| **G** | Single → Single (из каталога) | та же ячейка | только **начинка** | replace |
| **H** | занятый ↔ занятый (**drag** уже стоящего) | `D_a`↔`D_b` / `S_a`↔`S_b` | **меняются местами** (оба остаются) | live drag-swap |

**H ≠ F/G:** F/G — новый из каталога поверх занятого = replace (старый исчезает).  
**H** — тянешь уже стоящий на другой стоящий → обмен.  
Баг до gest16: во время drag `zoneIndex` сразу = зона цели → swap ломался → «заезжал и отлетал».  
**gest18:** drag Single в пустой Double = **split** (не растягивать корпус); S↔D swap запрещён.

**Запрещено:** push живого соседа вправо (сохранить старый S, сдвинув его).  
**Разрешено:** съесть → пустые ячейки оказываются справа / в конце ряда.

## 4. Почему у нас ломается (диагноз)

1. **Модель зон:** прямая секция часто = ряд **double-зон** (`evenAllDoubles` / partSize ≈ 2×cell), а не `allSingles` / N ячеек.  
2. **Жест B слишком широкий:** `module=single && zoneKind=double` → split **всегда**, в т.ч. на **пустой** double.  
3. **Призрак:** ширина = `snap.moduleWidth` зоны, без учёта `moduleDoorKind` → Single выглядит как Double.

Итог теста «ставлю однодверный слева на одинаковые ячейки»:
- Maatkasten: одна ячейка занята.
- Clodis: split → две single слева, справа doubles «остались».

## 5. Как исправлять в Clodis

### Фазы внедрения

| Фаза | Scope | Статус |
|------|--------|--------|
| **G0–G2 прямая** | дефолт = **allSingles** (ячейки); жесты; призрак 1/2 | **gest9** |
| **G3 угол** | жесты на свободном плече L; спец не трогаем | **gest24** |
| G3 bay/мост | bay, bridge | later |

**Спецсекции в угловом не трогаем:** `defaultStripVariantInternalIndex(..., section)` для угла/bay по-прежнему берёт первый double-ряд.

### G0 — старт сетки (gest12)

**Старт прямой (как Maatkasten):** первый **double-ряд** — сплошная / пунктир mid / сплошная. Счётчик = **1**.  
**«−»:** allSingles — все однодверные; на минимуме «—».  
**Single влево на double:** split **только этой** зоны (кликнутая half + пустая half). Остальные doubles **не** трогаем.  
**Запрещено:** резать всю секцию в singles при одном place (старый expand-all).

### G1 — призрак

- Single → **1** ячейка  
- Double → **2** соседние ячейки  

### G2 — жесты

- place-empty / replace — same cell  
- split — только **занятый** Double  
- eat-merge — Double на Single(+сосед)  

### Не трогать при порте

- Каталог, обклад, петли, свет IKEA, studio layer 1.  
- Ручной «+ / −» вариантов на шаге 4 (можно уйти с allSingles на doubles) — остаётся.

## 6. Чеклист приёмки (прямая)

1. **Новая** прямая (шаг 2 → создать заново): сразу равные **ячейки**, не double+пунктир mid.  
2. Призрак Single = 1 ячейка; Double = 2 ячейки.  
3. Single влево → одна занятая ячейка; справа пустые single.  
4. Угловая / bay — дефолт деления **как раньше** (не allSingles).  
5. Single на занятый Double → split в half.  
6. Double на Single(+сосед) → eat.  

> Старая секция, созданная до gest9, может остаться doubles — пересоздать прямую или сменить вариант на шаге 4 на «все одн.».
