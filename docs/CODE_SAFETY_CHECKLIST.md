# ✅ Чеклист безопасности кода

> **Проверка перед коммитом: убедиться что код не содержит прямого копирования из референса**

---

## 🔍 Перед каждым коммитом

### 1. Проверка на прямое копирование

- [ ] **Нет скопированных блоков кода**
  - Проверить: нет ли идентичных блоков кода из референса
  - Действие: если есть - переписать своим стилем

- [ ] **Нет скопированных комментариев**
  - Проверить: нет ли комментариев из референса
  - Действие: переписать своими словами

- [ ] **Нет скопированных имён переменных/функций**
  - Проверить: нет ли специфичных имён из референса
  - Действие: использовать свои имена

### 2. Проверка структуры

- [ ] **Структура кода отличается от референса**
  - Проверить: код написан в своём стиле
  - Действие: если структура идентична - переработать

- [ ] **Используются свои паттерны**
  - Проверить: код следует стилю проекта
  - Действие: привести к единому стилю

### 3. Проверка уникальных элементов

- [ ] **Уникальные синтаксисы изменены**
  - Проверить: нет ли специфичных синтаксисов из референса
  - Действие: использовать альтернативные подходы

- [ ] **Уникальные структуры данных изменены**
  - Проверить: нет ли специфичных структур из референса
  - Действие: использовать свои форматы

### 4. Проверка документации

- [ ] **Есть анализ референса**
  - Проверить: создан ли файл `*_REFERENCE_ANALYSIS.md`
  - Действие: создать если отсутствует

- [ ] **Есть план реализации**
  - Проверить: создан ли файл `*_IMPLEMENTATION_PLAN.md`
  - Действие: создать если отсутствует

- [ ] **Документированы отличия**
  - Проверить: описаны ли отличия от референса
  - Действие: добавить описание отличий

---

## 🛡️ Детальная проверка

### Проверка функций

Для каждой функции проверить:

- [ ] **Имя функции уникально**
  - Референс: `functionNameFromReference()`
  - Наш код: `ourFunctionName()` ✅

- [ ] **Логика переписана**
  - Референс: `if (a && b) return c;`
  - Наш код: `if (a && b) { return c; }` ✅ (другой стиль)

- [ ] **Алгоритм понятен**
  - Можно объяснить что делает функция
  - Не просто скопировано

### Проверка классов

Для каждого класса проверить:

- [ ] **Имя класса уникально**
- [ ] **Структура методов отличается**
- [ ] **Используются свои паттерны**

### Проверка данных

Для структур данных проверить:

- [ ] **Имена полей изменены** (если уникальные)
- [ ] **Формат данных отличается** (если уникальный)
- [ ] **Используются стандартные форматы** (JSON, стандартные структуры)

- ❌ Специфичные имена из референса
- ❌ Уникальные синтаксисы без изменений

### Ручная проверка

3. Сравнить визуально

## 📝 Примеры

### ❌ Плохо (копирование)
```javascript
// Референс
function calculatePivot(size, pivot) {
  return -pivot * size / 2;
}

// Наш код (ПЛОХО - копия)
function calculatePivot(size, pivot) {
  return -pivot * size / 2;
}
```

### ✅ Хорошо (переписанное)
```javascript
// Референс
function calculatePivot(size, pivot) {
  return -pivot * size / 2;
}

// Наш код (ХОРОШО - переписано)
function computeCenterOffset(dimension, offsetRatio) {
  return -offsetRatio * dimension / 2;
}
```
