## 🎯 Назначение компонента

**Что делает:**
Админ панель для управления конструктором мебели. Единый интерфейс с боковым меню для переключения между разделами.

**Где используется:**
Основной интерфейс администратора для настройки конструктора, каталогов, заявок и т.д.

**Ключевая функциональность:**
- Боковое меню (sidebar) с навигацией
- Переключение между страницами через показ/скрытие контейнеров
- Модульная структура - каждая страница = отдельный контейнер
- Vue.js компоненты для интерактивных страниц

## 🔄 Поток данных

### Сценарий 1: Переключение между страницами
```
1. Пользователь кликает на пункт меню
2. JavaScript обрабатывает клик (через data-page атрибут)
3. Скрываются все страницы (убирается класс active)
4. Показывается выбранная страница (добавляется класс active)
5. Если есть подменю - раскрывается/скрывается
```

### Сценарий 2: Загрузка данных страницы
```
1. Страница становится активной
2. Vue компонент инициализируется (если есть)
3. Запрос к API для загрузки данных
4. Отображение данных в таблице/форме
```

## 🧩 Основные функции/методы

### Структура HTML
**Назначение:** Все страницы в одном HTML файле, переключение через CSS классы

**Алгоритм:**
```
1. Каждая страница = <div id="page-id" class="admin-page">
2. По умолчанию все скрыты (display: none)
3. Активная страница получает класс "active" (display: block)
4. Боковое меню использует data-page атрибуты для связи
```

### Боковое меню (metismenu)
**Назначение:** Навигация между разделами

**Структура:**
```html
<ul class="nav metismenu" id="side-menu">
  <li>
    <a href="#page-id" data-page="page-id">
      <i class="fa fa-icon"></i>
      <span class="nav-label">Название</span>
    </a>
    <!-- Подменю (опционально) -->
    <ul class="nav nav-second-level collapse">
      <li><a href="#sub-page">Подпункт</a></li>
    </ul>
  </li>
</ul>
```

## 🎨 UI/UX особенности

### Интерфейс
- **Боковое меню** - фиксированное слева, ширина ~250px
- **Основной контент** - справа от меню, margin-left: 250px
- **Логотип** - в верхней части меню
- **Иконки** - Font Awesome для каждого пункта меню

### Взаимодействие
- **Клик на пункт меню** - переключение страницы
- **Клик на пункт с подменю** - раскрытие/скрытие подменю
- **Активный пункт** - выделяется визуально (класс active)

### Стили
- Использует `style_v2.css` из референса
- Bootstrap-подобные классы (ibox, ibox-title, ibox-content)
- Кастомные стили для меню и страниц
