# Smoke: комната целая

Перед «принято» по **любой** правке (особенно `perf`).  
Пользователь: да/нет. Агент: если сам смотрит в браузере — тот же список.

## Обязательно (всё да)

1. **Вид сверху** — стены/контур комнаты читаются, не одна каша в центре.
2. **Ряды/ячейки** — сетка вдоль стен, не свалена в точку у пивота.
3. **Размеры** — подписи у стен/модулей, не десятки меток в куче по центру.
4. **Модули** (если были) — стоят в ряду, не «взрыв» координат.

## Если хоть один пункт нет

- Правка **не принята**.
- Агент: **полный откат** этого изменения (не докручивать поверх).
- Дальше — другой узкий способ в том же режиме.

## Быстрый URL

Открыть текущий bust комнаты (см. ответ агента / `index.html` → `__CLD_BUILD`).  
Тулбар: сверху; при необходимости включить «Ячейки» / «Размеры» только для проверки, не как нормальный хаос.
