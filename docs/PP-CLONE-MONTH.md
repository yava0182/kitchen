## Definition of Done (месяц)

Клиент может:

1. Создать / открыть кухонный проект.
2. Расставить низ / верх / углы по правилам Clodis (прямая 600+жертва, НМУ freeze 1.42, накладки по канону).
3. Видеть модули из админки **как в карточке** (админка → комната).
4. Сохранить и снова открыть проект без потери ключевых полей.
5. Отправить заявку и/или увидеть **ориентир** цены.

**Вне DoD:** полный PP SaaS (декоры, техника, API, готовые проекты, полный прайс-движок, 1:1 UI).

## Календарь ~4 недели

| Неделя | Фокус | Результат |
|--------|--------|-----------|
| **W1** | Dump из ЛК PP | Критичные JSON в `docs/pp-dump/` + чеклист inventory зелёный по kitchen-critical |
| **W2** | Геометрия комнаты | Зелёные слои из очереди GREEN (прямая/угол/пояса без overlay-костылей) |
| **W3** | Админка → сцена + save | Столешка/цоколь/дерево карточки в комнате; draft save/load стабилен для демо |
| **W4** | Коммерческий минимум | Заявка + ориентир цены; MISS меню остаются stub |

Правила исполнения: один слой = одно сообщение Auto; приёмка да/нет; Chrome в PP только под конкретный слой; не менять канон НМУ без явной фразы.

## Что сознательно не обещаем

- Пиксель-в-пиксель UI всего PlanPlace.
- Полный каталог встраиваемой техники / интерьера / коммуникаций.
- API и интеграции «как у PP».
- Полный прайс-движок PP.
- Слепой порт всего `vendor/main_core_v2*` вместо принятых канонов.
