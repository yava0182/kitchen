Управление комнатой

Категории каталога в комнате

Выберите типы каталога, которые будут отображаться в комнате. Для каждого типа можно ограничить список категорий (если не отмечено — в комнате показываются все категории этого типа).

Поведение в комнате

Применяется при размещении модуля. Поля «высота от/до» ниже — только ограничения при редактировании в попапе.

В одной ячейке: base + upper с одной группой. full ни с кем не делится.

Одинаковая метка у пары (гостиная / прихожая). Пусто = не делит ячейку. Пример: wall_column, hallway_entry.

Шаг 4

Настройка размеров секций (вариантов деления)

Задайте допустимый диапазон ширины одной внутренней секции (мм) и шаг сетки (например 100 мм = 10 см): варианты деления на шаге 4 учитываются только если ширина секции кратна этому шагу.

Одностворчатые: 400–600 мм; двустворчатые: 800–1200 мм
Например 100 = шаг 10 см; ширина секции = кратна этому значению
Вилка для схемы «N×2S + 1×S» (двойные слева, одинар справа)
Сохранено ✓

У каждого отверстия: mountSide — в пласть или в торец; для L (тип 2): деталь по направлению сверления — ±X (влево/вправо) = вертикаль, ±Y (вниз/вверх) = горизонталь; поле «Деталь» — только override; для конфирмата T-стыка: Ø8×16 в пласть полки (h), Ø5 в торец стойки (v).
