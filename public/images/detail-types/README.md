# Папка для изображений типов деталей

Поместите сюда изображения превью для типов деталей.

## Структура файлов

Изображения должны быть названы следующим образом:

1. `back_front.png` - Задняя фронтальная
2. `vertical_left.png` - Вертикальная левая
3. `vertical_right.png` - Вертикальная правая
4. `horizontal_top.png` - Горизонтальная верхняя
5. `horizontal_bottom.png` - Горизонтальная нижняя
6. `vertical_middle.png` - Вертикальная средняя
7. `horizontal_middle.png` - Горизонтальная средняя
8. `front_middle.png` - Фронтальная средняя
9. `front_front.png` - Фронтальная передняя

## Формат изображений

- Формат: PNG или JPG
- Размер: рекомендуется 100x100 пикселей или больше (квадратные)
- Прозрачность: поддерживается (для PNG)

## Использование

После добавления изображений они будут автоматически использоваться в модалке выбора типа детали вместо сгенерированных на canvas превью.
