# Kitchen playground (эксперимент)

Отдельная копия конструктора под **кухни**. Шкафы живут в `../Configurator-Clodis-ThreeJS-7/` и сюда **не импортируются**.

## Зачем так

- Шкафы не ломаются экспериментами кухни.
- Потом можно: оставить раздельно, вынести в другой репозиторий, или слить общий core (3D, расстановка, крепёж) + линии `wardrobe` / `kitchen`.

## Что уже есть

Полный снимок движка: комната, админка, 3D, крепёж, расстановка, «Управление комнатой 2».
Модели шкафов в каталоге можно удалить или оставить пустыми — движок остаётся.

## Порты (не пересекаются со шкафами)

| | Шкафы | Кухня |
|--|-------|-------|
| Vite | 8000 | **8100** |
| API | 8001 | **8101** |

Запуск: `LAUNCH_SERVER.bat` или `npm run dev:all` (после `npm install`).

- Комната: http://localhost:8100/
- Админка: http://localhost:8100/admin-new.html
- Управление комнатой 2: http://localhost:8100/admin-room-management-2.html

## Git

Свой репозиторий здесь, ветка `kitchen-playground`. `Configurator-Clodis-ThreeJS-7` / `main` не трогается.

## Правила

1. Не копировать правки кухни обратно в Seven «заодно».
2. Общий код — осознанный cherry-pick / пакет, не symlink из шкафов.
3. Для кухни — отдельный чат / корень Cursor на эту папку.
