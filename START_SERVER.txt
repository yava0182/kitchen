  ИНСТРУКЦИЯ ПО ЗАПУСКУ НА СЕРВЕРЕ
═══════════════════════════════════════════════════════════

📦 РАЗРАБОТКА (Development):
───────────────────────────────────────────────────────────
1. Запустить Vite (фронтенд) на порту 8000:
   npm run dev

2. Запустить Express сервер (API) на порту 3001:
   npm run dev:server

   ИЛИ запустить оба одновременно:
   npm run dev:all

───────────────────────────────────────────────────────────

🚀 ПРОДАКШЕН (Production):
───────────────────────────────────────────────────────────
1. Собрать проект:
   npm run build

2. Запустить продакшен сервер:
   npm start

   Сервер автоматически определит режим продакшена, если папка dist/ существует.
   Сервер будет:
   - Обслуживать статические файлы из папки dist/
   - Обрабатывать API запросы (/api/*, /catalog/*)
   - Работать на порту 3001 (или PORT из переменной окружения)
   - Возвращать index.html для всех маршрутов (SPA)

───────────────────────────────────────────────────────────

🌐 НАСТРОЙКА ДЛЯ САЙТА:
───────────────────────────────────────────────────────────
1. После сборки (npm run build) все файлы будут в папке dist/

2. Сервер автоматически:
   - Обслуживает статические файлы из dist/
   - Обрабатывает API запросы
   - Возвращает index.html для всех маршрутов (SPA)

3. Для изменения порта:
   set PORT=8080
   npm start

4. Для работы на другом домене:
   - В продакшене API URL автоматически становится относительным
   - Все запросы идут на тот же домен, где размещено приложение

───────────────────────────────────────────────────────────

📝 ПЕРЕМЕННЫЕ ОКРУЖЕНИЯ:
───────────────────────────────────────────────────────────
PORT=3001            - Порт сервера (по умолчанию 3001)

   Примечание: Режим продакшена определяется автоматически
   по наличию папки dist/. Если нужно принудительно установить:
   - Windows: set NODE_ENV=production
   - Linux/Mac: export NODE_ENV=production

───────────────────────────────────────────────────────────

✅ ПРОВЕРКА РАБОТЫ:
───────────────────────────────────────────────────────────
1. Откройте в браузере: http://localhost:3001
2. Проверьте API: http://localhost:3001/api/health
3. Проверьте каталог: http://localhost:3001/catalog/items_list/
